二、常见问题解答（FAQ）

1. 我的作品保存在哪里？会上传到云端吗？

PPaint 完全离线运行。您的所有画作、图层、自定义画笔及应用设置均保存在您的设备本地存储中，不会上传至任何云端或外部服务器。卸载应用前，建议通过导出功能备份您的作品文件。

2. 如何找到并使用「AR 人脸预览」功能？

「AR 人脸预览」可将您的二维画布实时映射至三维面部网格上，方便设计面部彩绘、妆面与贴纸。具体操作路径如下：

  1. 打开 PPaint，在「作品库」中新建（点击 +）或打开任意作品进入画布工作台（建议使用方形画布，如 2048 × 2048）；
  2. 在画布工作台顶部工具栏左侧，点击 •••（操作） 按钮；
  3. 在弹出菜单的 「辅助」 分组下，点击 「AR 人脸预览」；
  4. 点击 「生成 UV 模板图层」，可将 ARKit 人脸网格的 UV 展开线框作为新图层导入当前画作（可撤销、隐藏或删除），方便对照五官区域绘制；
  5. 点击 「继续并允许使用摄像头」（或 「开始预览」），即可通过前置原深感摄像头将当前画布（不含背景色）实时贴合到您的面部预览三维效果。

3. 为什么提示「本设备不支持人脸跟踪」？

「AR 人脸预览」依赖配备前置原深感摄像头（TrueDepth Camera，即支持面容 ID）的 iPhone 或 iPad。如果您的设备不支持原深感摄像头，常规绘画与编辑功能不受任何影响。

4. PPaint 支持导入和导出哪些文件格式？

  • 作品与画笔：支持 .ppaint 原生作品包、.ppbrushes 画笔包，以及兼容导入常见第三方画笔与色板文件；
  • 图像与视频：支持导入与导出 PSD（保留图层结构）、PNG、JPEG、TIFF 图像，以及导出绘画过程的缩时回放视频（MP4 / MOV）。

5. 如果拒绝了相册或相机权限怎么办？

绘画与本地保存完全不依赖任何系统权限。如果您后续需要将导出图像存入系统「照片」或使用「AR 人脸预览」，可随时前往系统 「设置」→「App」→「PPaint」 中开启照片（仅添加）或相机权限。

三、隐私政策与原深感摄像头（TrueDepth API）说明

PPaint 严格遵循隐私保护原则设计：

  • 零数据收集与完全离线：本应用不包含任何网络请求代码，不接入任何第三方统计、分析或广告 SDK，不收集、不存储、不传输也不共享您的任何个人信息或创作内容。
  • 照片库权限说明：仅在您主动选择将导出作品或视频保存到系统「照片」应用时，使用「仅添加照片」权限写入文件；PPaint 不会读取您相册中的已有照片。
  • 原深感摄像头与面容数据（TrueDepth API / Face Data）披露：
    • 访问的数据与用途：在支持原深感摄像头的设备上，仅当您主动打开可选的「AR 人脸预览」功能（工作台 → •••（操作） → 辅助 → AR 人脸预览）时，PPaint 会调用 Apple 系统 ARKit（ARFaceTrackingConfiguration、ARSCNFaceGeometry 与 ARFaceGeometry），仅用于在画布上生成二维人脸 UV 线框参考图层，以及将您的二维画布作为漫反射贴图实时渲染在三维面部网格上预览。
    • 存储与保留策略：所有摄像头画面与面部网格几何数据仅在设备本机内存中实时处理与渲染，绝不录制、绝不写入磁盘保存、绝不持久化保留。当您关闭「AR 人脸预览」面板或将应用切换至后台时，AR 会话与摄像头访问会立即停止。
    • 第三方共享说明：本应用绝不会将任何摄像头画面或面容数据发送至设备外部，也不会与任何第三方共享。
